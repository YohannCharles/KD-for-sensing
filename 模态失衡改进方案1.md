# 给 Codex 的实现说明：通信多模态失衡的反事实可靠性感知融合框架

## 0. 方法名称

实现一个通用通信多模态波束预测框架：

```text
CRAF: Counterfactual Reliability-Aware Fusion
```

中文含义：

```text
反事实可靠性感知融合
```

目标是处理通信多模态失衡问题，支持：

```text
1. 任意模态数量
2. 任意模态组合
3. 模态缺失
4. 简单数据集：所有单模态都有效
5. 复杂数据集：部分单模态越训练越差
6. current beam prediction 和 future beam prediction
7. 单模态、朴素多模态、可靠性感知多模态三个层级实验
```

---

# 1. 总体结构

模型输入是历史窗口：

```text
τ = t-W+1, ..., t
```

模型输出是未来波束：

```text
τ = t+1, ..., t+H
```

其中：

```text
W: history length，比如 8
H: prediction horizon，比如 1 或 5
C: beam 类别数，比如 64
K: 模态数量，比如 image / lidar / radar / gps / mmwave
```

整体结构：

```text
每个模态历史输入
    ↓
模态专属 feature extractor / projector
    ↓
统一维度 token
    ↓
+ 时间位置编码
+ 模态编码
    ↓
可靠性估计器，输出 r_m
    ↓
r_m · token
    ↓
Transformer Encoder / Set Transformer / GRU baseline
    ↓
future horizon query attention
    ↓
beam classifier
    ↓
beam(t+1), ..., beam(t+H)
```

## 3.1 Dataset 返回格式

`Dataset.__getitem__` 返回一个 dict：

```python

    "features": {
        "image": Tensor[W, D_image] 或 Tensor[W, C, H, W],
        "lidar": Tensor[W, D_lidar] 或 raw lidar,
        "radar": Tensor[W, D_radar],
        "gps": Tensor[W, D_gps],
        "mmwave": Tensor[W, D_mmwave],
    },
    "available_modalities": {
        "image": bool,
        "lidar": bool,
        "radar": bool,
        "gps": bool,
        "mmwave": bool,
    },
    "labels": Tensor[H],              # long, 每个 future step 的 beam index
    "beam_power": Optional[Tensor[H, C]],  # 可选，若有 RSRP / beam power profile

```

推荐优先支持**预提取特征**：

```text
image:   [W, D_image]
lidar:   [W, D_lidar]
radar:   [W, D_radar]
gps:     [W, D_gps]
mmwave:  [W, D_mmwave]
```

这样先不用在主模型里实现复杂 image / lidar / radar backbone，方便快速验证方法。


用途：

将各模态时序特征转成 token set。

输入：



其中：



```python
tokens = torch.stack([z_image, z_lidar, z_radar, z_gps, z_mmwave], dim=1)

```

padding mask：

```python
token_padding_mask = ~modality_mask[:, :, None].expand(B, K, W)
# [B, K, W]
```

## 5.3 单模态预测头，用于 confidence 和 auxiliary loss

文件：

```text
models/prediction_heads.py
```

每个模态有一个轻量预测头：

```python
class UniModalHead(nn.Module):
    def __init__(self, d_model: int, horizon: int, num_beams: int):
        ...

    def forward(self, modality_tokens: torch.Tensor) -> torch.Tensor:
        """
        modality_tokens: [B, W, D]
        return logits: [B, H, C]
        """
```

实现：

```text
1. mean pooling over W
2. Linear(D → H*C)
3. reshape to [B, H, C]
```

后续可以升级为 GRU/Transformer，但最小实现先用 mean pooling。

计算单模态 confidence：

```python
prob = softmax(logits, dim=-1)
entropy = -sum(prob * log(prob)) / log(C)
confidence_entropy = 1 - entropy

top2 = topk(prob, k=2)
margin = top1_prob - top2_prob

confidence = concat([
    confidence_entropy_avg_over_H,
    margin_avg_over_H,
])
```

输出：

```python
confidence_features: Tensor[B, K, 2]
unimodal_logits: Tensor[B, K, H, C]
```

## 5.4 ReliabilityEstimator

文件：

```text
models/reliability.py
```

目标：

给每个样本、每个模态输出可靠性：

```python
r: Tensor[B, K]
```

输入：

```python
modality_repr: Tensor[B, K, D]    # 每个模态 token over W 后的 pooled 表示
confidence: Tensor[B, K, 2]       # 单模态预测置信度
dataset_prior: Tensor[K]          # EMA 模态先验
modality_mask: Tensor[B, K]
```

推荐构造：

```python
modality_repr = masked_mean(tokens, dim=time)
```

Reliability MLP 输入：

```python
input_m = concat([
    modality_repr[b, k],          # D
    confidence[b, k],             # 2
    dataset_prior[k],             # 1
    modality_embedding[k],        # D
])
```

输出：

```python
logit_r[b, k]
r[b, k] = sigmoid(logit_r[b, k])
```

不可用模态：

```python
r = r * modality_mask.float()
```

类签名：

```python
class ReliabilityEstimator(nn.Module):
    def __init__(
        self,
        d_model: int,
        num_modalities: int,
        hidden_dim: int = 256,
        use_confidence: bool = True,
        use_dataset_prior: bool = True,
        prior_init: float = 0.5,
        ema_momentum: float = 0.95,
    ):
        ...

    def forward(
        self,
        modality_repr: torch.Tensor,     # [B, K, D]
        confidence: Optional[torch.Tensor],  # [B, K, 2]
        modality_mask: torch.Tensor,     # [B, K]
        modality_emb: Optional[torch.Tensor] = None, # [K, D]
    ) -> Dict[str, torch.Tensor]:
        """
        return:
        {
            "r": [B, K],
            "r_logits": [B, K],
            "dataset_prior": [K],
        }
        """

    @torch.no_grad()
    def update_prior(
        self,
        modality_indices: torch.Tensor,
        contribution_targets: torch.Tensor,
    ):
        """
        modality_indices: [N]
        contribution_targets: [N] in [0, 1]
        用 EMA 更新 dataset_prior
        """
```

EMA 更新规则：

```python
prior[k] = ema_momentum * prior[k] + (1 - ema_momentum) * mean_target_for_k
```

## 5.5 Reliability Gate

文件可以放在：

```text

```

```python

```

```python
gated_tokens = tokens * r[:, :, None, None]
```

可选残差门控，防止早期把 token 完全压死：

```python
effective_r = min_gate + (1 - min_gate) * r
```


公式：

```python
gated_tokens = tokens * effective_r[:, :, None, None]
```

# 6. 主模型 CRAFModel

文件：

```text
models/craf_model.py
```

## 6.1 forward 输入

```python
outputs = model(
    features=batch["features"],
    modality_mask=batch["modality_mask"],
    force_modality_mask=None,
    return_unimodal=True,
)
```

`force_modality_mask` 用于训练时做 modality dropout 或 counterfactual 删除。

最终有效 mask：

```python
effective_modality_mask = modality_mask & force_modality_mask
```

如果 `force_modality_mask is None`：

```python
effective_modality_mask = modality_mask
```

## 6.2 forward 输出

```python
outputs = {
    "logits": Tensor[B, H, C],
    "r": Tensor[B, K],
    "r_logits": Tensor[B, K],
    "effective_modality_mask": Tensor[B, K],
    "unimodal_logits": Tensor[B, K, H, C],
    "confidence": Tensor[B, K, 2],
    "memory": Tensor[B, K*W, D],
    "memory_padding_mask": Tensor[B, K*W],
}
```

## 6.3 forward 流程

```python
token_out = tokenizer(features, effective_modality_mask)
tokens = token_out["tokens"]                         # [B,K,W,D]
token_padding_mask = token_out["token_padding_mask"] # [B,K,W]

unimodal_logits = compute_unimodal_logits(tokens)
confidence = compute_confidence(unimodal_logits)

modality_repr = masked_mean_over_time(tokens, token_padding_mask)

rel_out = reliability_estimator(
    modality_repr=modality_repr,
    confidence=confidence,
    modality_mask=effective_modality_mask,
    modality_emb=tokenizer.modality_embedding.weight,
)

r = rel_out["r"]  # [B,K]

gated_tokens = tokens * (min_gate + (1 - min_gate) * r[:, :, None, None])

fusion_out = fusion(gated_tokens, token_padding_mask)

pred_out = predictor(
    memory=fusion_out["memory"],
    memory_padding_mask=fusion_out["memory_padding_mask"],
)

return outputs
```

## 7.2 EarlyConcatGRU

复现旧结构：

```text
各模态 feature extractor / projector
concat
Fusion Linear
GRU
Multi-head attention prediction module
Classifier
```

实现细节：

```python
每个时间步 concat 所有有效模态特征
缺失模态填 0
concat_feat: [B, W, sum(D_m)]
fusion_linear: sum(D_m) -> d_model
GRU: [B, W, d_model] -> [B, W, d_model]
最后 hidden 或 horizon query predictor 输出 [B,H,C]
```

和 `EarlyConcatGRU` 相同，只是 GRU 换成 Transformer Encoder。

## 7.4 TokenTransformerFusion

不使用 reliability，只使用 token 化 + Transformer：

```text
tokens = feature + time emb + modality emb
直接送入 Transformer
不乘 r_m
```

这个 baseline 用于证明：

```text
token 化和 Transformer 还不够，可靠性 gate 才是关键。
```

## 7.5 CRAF

最终方法：

```text
TokenTransformerFusion + ReliabilityEstimator + Counterfactual gate supervision
```

## 8.2 Beam-aware Soft Label Loss

目的：

通信 beam 有邻近结构。预测相邻 beam 不应该和预测很远 beam 等价。

输入：

```python
labels: [B,H]
num_beams: C
sigma: float
circular: bool
```

构造 soft target：

```python
distance(k, y) = abs(k - y)
if circular:
    distance = min(abs(k-y), C-abs(k-y))

soft_target[k] = exp(-distance(k,y)^2 / (2*sigma^2))
soft_target = soft_target / soft_target.sum()
```

loss：

```python
KLDivLoss(
    log_softmax(logits, dim=-1),
    soft_target
)
```

函数：

```python
def beam_soft_label_loss(
    logits: torch.Tensor,   # [B,H,C]
    labels: torch.Tensor,   # [B,H]
    sigma: float = 1.5,
    circular: bool = False,
    ignore_index: int = -100,
):
    """
    return scalar loss
    """
```

```python
labels: [B,H]
modality_mask: [B,K]
r: [B,K]
```

warm-up 阶段：

```python
weight = modality_mask.float()
```

正式阶段：

```python
weight = detach(r) * modality_mask.float()
```

原因：

```text
不要强迫弱模态永远单独学好。
弱模态如果可靠性低，其单模态 auxiliary loss 权重也应该降低。
```

loss：

```python
loss_uni = sum_k weight_k * CE(unimodal_logits[:, k], labels)
```

---

## 8.4 Gate Reliability Loss

来自反事实贡献监督。

对某个模态 `m`：

```python
delta_m = loss_drop_m - loss_full
target_m = sigmoid(delta_m / tau)
```

其中：

```text
delta_m > 0：删除模态后 loss 变大，说明该模态有帮助，target 接近 1
delta_m < 0：删除模态后 loss 变小，说明该模态有害，target 接近 0
```

loss：

```python
BCEWithLogitsLoss(r_logits[:, m], target_m)
```

函数：

```python
def gate_bce_loss(
    r_logits: torch.Tensor,       # [B,K]
    targets: torch.Tensor,        # [B,K], invalid 位置任意
    target_mask: torch.Tensor,    # [B,K], True 表示该位置有 target
):
    """
    return scalar
    """
```

---

## 8.5 KD Loss，可选

如果以后使用 teacher：

```python
teacher_logits: Dict[str, Tensor[B,H,C]]
student_logits: Tensor[B,H,C]
teacher_weights: Tensor[B,num_teachers]
```

计算：

```python
p_teacher_i = softmax(teacher_logits_i / T)
p_teacher = sum_i alpha_i * p_teacher_i

loss_kd = KL(
    log_softmax(student_logits / T),
    p_teacher
) * T^2
```

teacher 权重：

```python
alpha_i = softmax(reliability_score_i / T_weight)
```

没有 teacher 时：

```python
kd_weight = 0
```

---

## 8.6 总 loss

```python
loss = (
    ce_weight * loss_ce
    + beam_soft_weight * loss_beam_soft
    + gate_weight * loss_gate
    + uni_weight * loss_uni
    + kd_weight * loss_kd
)
```

# 9. 反事实可靠性计算

文件可放在：

```text
train.py
```

或单独：

```text
utils/counterfactual.py
```

## 9.1 主思想

对当前有效模态集合 `S`：

```python
loss_full = Loss(model(S), y)
```

删除一个模态 `m`：

```python
loss_drop = Loss(model(S \ m), y)
```

贡献：

```python
delta_m = loss_drop - loss_full
```

目标：

```python
target_m = sigmoid(delta_m / tau)
```

## 9.2 训练时计算方式

为了节省显存，删除模态分支使用：

```python
with torch.no_grad():
    outputs_drop = model(..., force_modality_mask=drop_mask)
```

但 full forward 要正常反向传播。

伪代码：

```python
outputs_full = model(features, modality_mask, force_modality_mask=train_mask)

loss_main, per_sample_full = compute_main_loss(outputs_full, labels)

if epoch >= cf_start_epoch:
    selected_modalities = sample_modalities_for_counterfactual(
        effective_mask=outputs_full["effective_modality_mask"],
        mode=config.counterfactual.mode,
    )

    gate_targets = zeros[B,K]
    gate_target_mask = zeros[B,K].bool()

    for m in selected_modalities:
        drop_mask = train_mask.clone()
        drop_mask[:, m] = False

        # 保证每个样本至少保留一个模态
        drop_mask = ensure_min_keep(drop_mask, original_mask=modality_mask, min_keep=1)

        with torch.no_grad():
            outputs_drop = model(features, modality_mask, force_modality_mask=drop_mask)
            _, per_sample_drop = compute_ce_or_main_per_sample(outputs_drop, labels)

        delta = per_sample_drop - per_sample_full.detach()
        target = sigmoid(delta / tau)

        valid = outputs_full["effective_modality_mask"][:, m] & has_at_least_one_after_drop

        gate_targets[valid, m] = target[valid]
        gate_target_mask[valid, m] = True

    loss_gate = gate_bce_loss(
        r_logits=outputs_full["r_logits"],
        targets=gate_targets,
        target_mask=gate_target_mask,
    )

    model.reliability_estimator.update_prior(
        modality_indices,
        contribution_targets,
    )
else:
    loss_gate = 0
```

## 9.3 选择删除哪些模态

支持两种模式：

```yaml
counterfactual:
  mode: "sample_one"
```

### sample_one

每个 batch 随机选 1 个当前存在的模态做 leave-one-out。

优点：

```text
快，适合日常训练。
```

### leave_one_out

对所有存在模态都做一次 leave-one-out。

优点：

```text
可靠性监督更全。
```

缺点：

```text
计算量约增加 K 倍。
```

建议：

```text
主训练用 sample_one
小规模 ablation 用 leave_one_out
```

```python
def sample_modality_dropout_mask(
```

# 13. 训练阶段

## Stage 1：Warm-up

配置：

```yaml
warmup_epochs: 5
cf_start_epoch: 6
```

做法：

```text
1. 不启用 counterfactual gate loss
2. 启用 CE loss
3. 启用 beam soft loss
4. 启用 unimodal auxiliary loss
5. reliability gate 可以 forward，但不强监督
```

可选：

```text
warm-up 阶段 r_m 可以直接设为 1，或者使用 estimator 输出。
建议实现参数 reliability_warmup_mode:
    "all_one"
    "learned"
```

默认：

```text
all_one
```

即 warm-up 阶段不让随机 r 干扰训练。

---

## Stage 2：Counterfactual Reliability Training

从 `cf_start_epoch` 开始：

```text
1. 启用 reliability estimator
2. 启用 counterfactual leave-one-out target
3. 启用 gate BCE loss
4. 更新 dataset-level prior
5. 继续 modality dropout
```

---

## Stage 3：Optional KD

如果以后加入 teacher：

```text
1. 加载 teacher logits 或 teacher checkpoint
2. 用 reliability 权重做 teacher ensemble
3. 加 KD loss
```

当前版本先保留接口，默认不启用。

# 14. train.py 主循环伪代码

```python
for epoch in range(num_epochs):
    model.train()

    for batch in train_loader:
        batch = move_to_device(batch, device)

        modality_mask = batch["modality_mask"]

        if cfg.training.modality_dropout.enabled:
            force_mask = sample_modality_dropout_mask(
                modality_mask,
                drop_prob=cfg.training.modality_dropout.drop_prob,
                min_keep=cfg.training.modality_dropout.min_keep,
            )
        else:
            force_mask = modality_mask

        outputs = model(
            features=batch["features"],
            modality_mask=modality_mask,
            force_modality_mask=force_mask,
            reliability_mode="all_one" if epoch < warmup_epochs else "learned",
            return_unimodal=True,
        )

        losses = compute_losses(
            outputs=outputs,
            labels=batch["labels"],
            beam_power=batch.get("beam_power", None),
            cfg=cfg,
            epoch=epoch,
        )

        loss_total = losses["total"]
        per_sample_full = losses["per_sample_main"].detach()

        if cfg.training.counterfactual.enabled and epoch >= cfg.training.cf_start_epoch:
            cf_loss, cf_logs = compute_counterfactual_gate_loss(
                model=model,
                batch=batch,
                outputs_full=outputs,
                per_sample_full=per_sample_full,
                base_force_mask=force_mask,
                cfg=cfg,
            )
            loss_total = loss_total + cfg.loss.gate_weight * cf_loss
            losses["gate"] = cf_loss

        optimizer.zero_grad()
        scaler.scale(loss_total).backward()

        if cfg.training.grad_clip is not None:
            scaler.unscale_(optimizer)
            torch.nn.utils.clip_grad_norm_(model.parameters(), cfg.training.grad_clip)

        scaler.step(optimizer)
        scaler.update()

        scheduler.step_if_needed()

        log_train(...)
```

# 18. 关键实现细节和坑

## 18.1 防止所有模态都被 drop

每个样本至少保留一个模态：

```python
min_keep = 1
```

如果未来想保证通信模态一定存在，可以增加：

```yaml
force_keep_modalities: ["mmwave"]
```

但默认不要强制，这样方法才通用。

---

## 18.2 可靠性 gate 不要直接从 0 开始

建议：

```python
effective_r = min_gate + (1 - min_gate) * r
min_gate = 0.05
```

否则训练早期某个模态被压到 0 后很难恢复。

---

## 18.3 counterfactual target 必须 detach

```python
delta = per_sample_drop.detach() - per_sample_full.detach()
target = sigmoid(delta / tau)
```

不要让反事实 target 反向传播。

---

## 18.4 删除模态分支用 no_grad

```python
with torch.no_grad():
    outputs_drop = model(...)
```

否则显存和时间都会爆炸。

---

## 18.5 对不可用模态不计算 gate loss

```python
target_mask[b, k] = effective_modality_mask[b, k] and drop_valid
```

缺失模态、被原始数据 mask 掉的模态，不参与 gate BCE。

---

## 18.6 训练初期不要太依赖 gate

建议：

```text
epoch < warmup_epochs: r = 1
epoch >= warmup_epochs: r = learned
```

也可以对 gate loss 做 ramp-up：

```python
gate_weight_epoch = gate_weight * min(1, (epoch - cf_start_epoch + 1) / 5)
```

---

## 18.7 单模态 auxiliary loss 后期要可靠性加权

复杂场景中 image/lidar/radar 单模态可能越训越差。

不要一直强迫所有单模态 head 学好。

正式阶段：

```python
uni_weight_m = detach(r_m)
```

---

## 18.8 Transformer mask 形状

输入：

```python
memory: [B, N, D]
src_key_padding_mask: [B, N]
```

`src_key_padding_mask=True` 表示该 token 被忽略。

```text
This repository implements Counterfactual Reliability-Aware Fusion (CRAF) for multimodal beam prediction. CRAF estimates the conditional contribution of each modality by comparing the prediction loss with and without that modality. The learned reliability scores are used to dynamically gate modality tokens before fusion, enabling robust prediction under modality imbalance, missing modalities, and varying modality combinations.
```

