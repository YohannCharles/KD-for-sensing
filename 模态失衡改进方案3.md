下面是一份可以直接发给 Codex 的**完整程序改进方案**。假设当前程序就是你最近跑出结果图的版本，已经有：

`token_transformer_all_modalities_no_kd`、`craf_all_modalities_no_counterfactual`、`craf_all_modalities_stabilized_no_kd`、`craf_all_modalities_fixed_prior_sanity` 这些配置和日志。

这次改进目标是：

> 把当前 CRAF 从“端到端直接学 gate”改成 **Teacher 初始化 + Prior-guided gate + 选择性微调** 的三阶段训练框架，减少弱模态过拟合和错误 gate 学习。

---

# 0. 当前问题定位

最近结果显示：

```text
1. token_transformer_all_modalities_no_kd:
   train acc 很高，但 val acc 最低，说明 naive all-modal token fusion 过拟合弱模态噪声。

2. fixed_prior_sanity:
   手动设置 image/radar/lidar=0.15, gps/mmwave=0.9 后 val acc 最好。
   说明场景 32 中确实存在明显模态失衡。

3. stabilized_no_kd:
   反事实 gate 会把 image/lidar 也推得很高，说明当前基于 train loss 的 counterfactual target 会高估弱模态贡献。

4. 所以下一版不要继续只调 warmup，而是引入：
   - 单模态 teacher 可靠性
   - prior initialized gate
   - learnable residual gate
   - selective fine-tuning
   - 可选 reliability-weighted KD
```

---

# 1. 新训练流程总览

实现三阶段训练：

```text
Stage 1: Train single-modal teachers
    image teacher
    lidar teacher
    radar teacher
    gps teacher
    mmwave teacher

Stage 2: Train multimodal fusion student
    加载 Stage 1 的 teacher encoder
    冻结 teacher encoder
    用 teacher val metric 初始化 modality prior
    训练 fusion transformer + reliability gate + prediction head
    默认不开 counterfactual
    默认不开 unimodal aux
    可选 weak KD

Stage 3: Selective fine-tuning
    从 Stage 2 best checkpoint 加载
    解冻 GPS/mmWave encoder，小学习率
    image/lidar/radar 默认继续冻结
    保留 prior regularization
    可选开启 relative/shuffle counterfactual
```

```python
class SingleModalTeacher(nn.Module):

        self,
```

结构：

```text
input [B, W, D_m]
    ↓
ModalityProjector
    ↓
+ time embedding
+ modality embedding
    ↓
Transformer Encoder
    ↓
HorizonQueryPredictor
    ↓
```

```python
{

```

注意：`features` 后面 Stage 2 可以复用为 teacher encoder 输出。

## 4.1 Prior 计算规则

支持两种模式。

### 模式 A：手动 prior，默认用于 Scene32

```python
manual_prior = {
    "image": 0.20,
    "lidar": 0.15,
    "radar": 0.20,
    "gps": 0.85,
    "mmwave": 0.90,
}
```

### 模式 B：根据 teacher val metric 自动计算

公式：

```python
score_m = 0.6 * val_acc_top1 + 0.2 * val_acc_top3 + 0.2 * val_adba
score_norm = (score_m - min_score) / (max_score - min_score + 1e-8)
prior_m = prior_min + (prior_max - prior_min) * score_norm
prior_m = clamp(prior_m, prior_min, prior_max)
```

默认：

```python
prior_min = 0.15
prior_max = 0.90
```

配置：

```yaml
teacher_registry:
  prior_mode: "manual"   # "manual" or "metric"
  manual_prior:
    image: 0.20
    lidar: 0.15
    radar: 0.20
    gps: 0.85
    mmwave: 0.90
```

## 5.2 Prior Residual Gate

新增文件：

```text
models/prior_gate.py
```

实现新的 gate：

```python
class PriorResidualGate(nn.Module):
    def __init__(
        self,
        modalities: List[str],
        d_model: int,
        prior: Dict[str, float],
        hidden_dim: int = 256,
        min_gate: float = 0.05,
        use_confidence: bool = True,
        use_modality_embedding: bool = True,
    ):
        ...
```

核心公式：

```python
prior_logit_m = logit(prior_m)
residual_logit_m = MLP([modality_repr, confidence, modality_emb])
gate_logit_m = prior_logit_m + residual_logit_m
raw_gate_m = sigmoid(gate_logit_m)
gate_m = min_gate + (1 - min_gate) * raw_gate_m
```

不可用模态：

```python
gate_m = gate_m * modality_mask
```

forward 输出：

```python
{
    "gate": gate,                    # [B, K]
    "gate_logits": gate_logits,      # [B, K]
    "prior": prior_tensor,           # [K]
    "residual_logits": residual,     # [B, K]
}
```

## 5.3 初始化要求

为了让 Stage 2 起点接近 fixed prior，`residual_logit` 最后一层初始化为 0：

```python
nn.init.zeros_(last_linear.weight)
nn.init.zeros_(last_linear.bias)
```

这样训练开始时：

```text
gate ≈ prior
```

这很重要。

## 5.4 Prior Regularization Loss

新增文件：

```text
losses/prior_losses.py
```

实现：

```python
def prior_regularization_loss(
    gate: torch.Tensor,          # [B, K]
    prior: torch.Tensor,         # [K]
    modality_mask: torch.Tensor, # [B, K]
    loss_type: str = "mse",
):
    ...
```

MSE 版本：

```python
loss = ((gate - prior[None, :]) ** 2)
loss = loss[modality_mask].mean()
```

也支持 L1：

```python
loss = abs(gate - prior)
```

Stage 2 推荐：

```yaml

```

Stage 3 推荐：

```yaml

```

## 6.2 Param groups

在 optimizer 构建时按模块设置不同 lr：

```python
param_groups = [
    {"params": fusion_params, "lr": 1e-4, "weight_decay": 1e-3},
    {"params": head_params, "lr": 1e-4, "weight_decay": 1e-3},
    {"params": gate_params, "lr": 1e-4, "weight_decay": 1e-3},
    {"params": gps_encoder_params, "lr": 3e-5, "weight_decay": 1e-4},
    {"params": mmwave_encoder_params, "lr": 3e-5, "weight_decay": 1e-4},
]
```

弱模态如果需要解冻，使用更小 lr：

```python
weak_encoder_lr = 1e-5
```

但默认不解冻。

# 7. Counterfactual 改进：作为可选项，不默认开启

当前版本的 counterfactual 会高估 image/lidar，因此 Stage 2/3 默认不开。

但代码需要保留并改进，方便后续 ablation。

## 7.1 新增 relative delta target

当前：

```python
target_m = sigmoid(delta_m / tau)
```

新增：

```python
centered_delta_m = delta_m - mean(delta_all_modalities)
target_m = sigmoid(centered_delta_m / tau)
```

配置：

```yaml
counterfactual:
  enabled: false
  mode: "relative_context_marginal"
  tau: 0.1
  ignore_eps: 0.03
  use_ce_only: true
```

忽略小贡献：

```python
if abs(centered_delta_m) < ignore_eps:
    ignore this target
```

## 7.2 新增 shuffle counterfactual

定义：

```python
delta_m = Loss(A + shuffled_m) - Loss(A + real_m)
```

如果真实模态比 batch 内打乱模态好，说明该模态确实包含 sample-specific 信息。

配置：

```yaml
counterfactual:
  enabled: false
  mode: "shuffle"
  tau: 0.1
  ignore_eps: 0.03
  use_ce_only: true
```

## 7.3 Counterfactual loss 不要用 focal/beam/aux

只用 CE 或 label-smoothed CE 的 per-sample loss：

```python
delta = ce_loss_counterfactual_only(...)
```

不要混入：

```text
beam soft
unimodal aux
KD
prior reg
gate loss
```

# 9. Loss 修改

当前主 loss 是 focal loss gamma=2。下一版建议支持并默认使用：

```text
CrossEntropy + label_smoothing=0.05
```

原因是 Scene32 中 hard samples 可能包含边界 beam 或噪声，focal gamma=2 容易过拟合 hard/noisy 样本。

实现 loss factory：

```python
def build_task_loss(cfg):
    if cfg.loss.task.type == "cross_entropy":
        return nn.CrossEntropyLoss(label_smoothing=cfg.loss.task.label_smoothing)
    elif cfg.loss.task.type == "focal":
        return FocalLoss(alpha=cfg.loss.task.alpha, gamma=cfg.loss.task.gamma)
```

总 loss：

```python
loss_total = (
    loss_task
    + beam_soft_weight * loss_beam_soft
    + prior_reg_weight * loss_prior
    + counterfactual_weight * loss_counterfactual_gate
    + kd_weight * loss_kd
    + unimodal_aux_weight * loss_unimodal_aux
)
```

Stage 2 默认：

```text
task = CE + label smoothing
beam_soft_weight = 0.03
prior_reg_weight = 0.05
unimodal_aux_weight = 0
counterfactual_weight = 0
kd_weight = 0
```

# 10. CRAFModel 修改

当前 CRAF 需要支持三种 gate 类型：

```yaml
gate.type:
  - "none"
  - "fixed_prior"
  - "prior_residual_sigmoid"
  - "old_sigmoid"
```

## 10.1 gate=none

用于 token transformer baseline：

```python
gate = torch.ones(B, K)
```

## 10.2 gate=fixed_prior

用于 sanity baseline：

```python
gate = prior[None, :].expand(B, K)
gate = gate * modality_mask
```

## 10.3 gate=prior_residual_sigmoid

用于新主实验：

```python
gate = PriorResidualGate(...)
```

# 17. 对当前版本的具体替换建议

当前 `craf_all_modalities_stabilized_no_kd` 的逻辑：

```text
前 25 轮 gate=1
第 26 轮开始 counterfactual gate
gate target 来自 train loss
```

新版本替换为：

```text
Stage 1:
    单模态 teacher 提供 encoder 和 prior

Stage 2:
    一开始 gate 就等于 teacher prior
    encoder 冻结
    不开 counterfactual
    只训练 fusion/gate residual/head
    prior regularization 防止 gate 乱跑

Stage 3:
    解冻 gps/mmwave 小学习率微调
    weak modality encoder 仍冻结
```

也就是说，不再依赖 `warmup_epochs=25` 来稳定 gate，而是用 teacher prior 让 gate 从合理位置开始。

# 19. 默认不要做的事

当前阶段不要默认启用：

```text
1. 全模态 encoder 全部解冻
2. image/lidar/radar 大学习率微调
3. 平均所有 teacher 的 KD
4. 强 unimodal auxiliary loss
5. 基于 train loss 的绝对 counterfactual target
6. focal gamma=2 作为唯一主 loss
7. CosineAnnealingWarmRestarts
```

这些都可能让模型重新走向“训练集更强、验证集更差”。

# 20. 一句话目标

这次改程序的核心目标是：

```text
把 CRAF 从“自己从 noisy training loss 里学习模态可靠性”，改成
“先用单模态 teacher 的验证表现建立可靠性先验，再让融合学生在该先验附近学习 sample-wise residual gate，并只选择性微调强模态 encoder”。
```

这样更符合你当前实验观察，也更容易超过 fixed prior baseline。
