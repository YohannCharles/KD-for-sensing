# Literature Matrix

本矩阵只记录与当前多模态 / 缺失模态 beam prediction 主线直接相关的文献和本仓库对照关系。它不是完整综述，也不下载 PDF、官方代码、数据或 checkpoint；缺官方 artifact、BibTeX 或 DOI 时显式标记 `pending` / `unavailable`。

状态口径：

- `official reproduction`：官方数据、权重、源码、环境和 exact test packaging 齐备。
- `local substitute`：本仓库本地替代实验，不等同官方结果。
- `source audit`：只记录官方/外部 artifact 可用性和 blocked reason。
- `background citation`：只作方法或数据背景引用。
- `not comparable`：split、label space、metric profile 或数据协议不一致。
