# 当前主线模型目录

本目录是 current 事实层：只列当前主线、baseline/control、诊断和 benchmark workflow。详细参数口径见 [experiment_protocols.md](experiment_protocols.md)，可引用结果和 blocked 状态见 [result_claims_registry.md](result_claims_registry.md)，纵向改进历史和创新线索见 [mainline_experiment_history.md](mainline_experiment_history.md)。

状态含义：

- `formal`：可作为当前正式实验协议运行或报告，仍需遵守对应 caveat。
- `lowmem`：正式协议的低内存工程变体，适合复核或资源受限运行。
- `smoke/debug`：只验证 schema、forward、runner 或配置继承，不用于论文结果比较。
- `diagnostic-only`：只读分析或 manifest 导出，不训练新模型。
- `local substitute`：本仓库本地替代实验，不等同 official reproduction。
- `local experimental baseline`：本仓库实验场景中的可训练 baseline，不声明论文官方复现。
