==================================================
二、为什么默认用 softmax 后概率
==================================================

默认展示 probability，也就是 softmax 后的概率分布。

原因：
1. probability 范围是 0 到 1，更适合人读
2. 64 类概率总和为 1，便于比较
3. GT confidence、GT rank、entropy、top1 margin 都更容易解释
4. logits 的尺度在不同模态 head 之间可能不一致，不适合默认跨模态直观比较

但是保留 logit 模式作为高级调试选项，用于检查不同模态 head 的 logit scale 是否异常。

字段说明：

1. modality
   image / lidar / radar / gps / mmwave / fusion

2. horizon
   t+1 / t+2 / ...

3. gt_beam
   当前 horizon 的真实 future beam label

4. top1_beam
   该模态在当前 horizon 上 argmax 的 beam

5. top1_value
   当前 view_type 下 top1 的值
   如果 probability 模式，就是 top1 probability
   如果 logit 模式，就是 top1 logit

6. gt_value
   当前 view_type 下 GT beam 对应的值
   如果 probability 模式，就是 P(GT)
   如果 logit 模式，就是 logit(GT)

7. gt_rank
   GT beam 在该模态分布中的排名
   rank 从 1 开始
   top1 则 rank=1

8. top1_minus_gt
   top1_value - gt_value

9. top1_top2_margin
   当前分布中 top1 和 top2 的差距
   用于判断分布尖锐程度

10. entropy
   只基于 probability 计算
   entropy = -sum(p * log(p + eps))
   如果没有 probability，则为 None

11. is_correct
   top1_beam == gt_beam

12. distance_to_gt
   abs(top1_beam - gt_beam)
   用于判断是不是邻近 beam 错误

数值保留 4 位小数。

十一、导出脚本建议
==================================================

如果项目里有 export_viewer_manifest.py，请增加 beam_distribution 导出。

输入：
- 每个模态每个 horizon 的 logits
- shape 推荐 [num_samples, H, num_beams]

导出时：
1. 保存 logit
2. 计算 softmax 得到 prob
3. 写入 samples.json 的 beam_distribution 字段

伪代码：

for sample_idx in range(num_samples):
    sample["beam_distribution"] = {}
    for modality in ["image", "lidar", "radar", "gps", "mmwave", "fusion"]:
        logits = modality_logits[modality][sample_idx]  # [H, C]
        probs = softmax(logits, axis=-1)
        sample["beam_distribution"][modality] = {
            "prob": probs.tolist(),
            "logit": logits.tolist()
        }

softmax 实现注意数值稳定：

def softmax(x, axis=-1):
    x = np.asarray(x, dtype=np.float64)
    x = x - np.max(x, axis=axis, keepdims=True)
    exp_x = np.exp(x)
    return exp_x / np.sum(exp_x, axis=axis, keepdims=True)
