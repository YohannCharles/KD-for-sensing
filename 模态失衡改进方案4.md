下面是一版可以直接发给 Codex 的完整改进方案。目标是：**在不写死 GPS/mmWave 强、Image/LiDAR/Radar 弱的前提下，实现一个自适应通信多模态融合架构，用于提升 clean all-modal Top-1，同时支持不同模态组合、模态缺失和不同数据集的优势模态变化。**

# Codex 实现任务：MARF 自适应路由多模态融合

## 0. 当前背景

当前已有版本包括：

```text
1. teacher_init_no_prior
   加载单模态 teacher encoder，无 gate，多模态融合训练。
   clean all-modal top1 表现很强，是当前强 baseline。

2. teacher_init_fixed_prior
   固定 prior gate，例如 image/lidar/radar 低，gps/mmwave 高。

3. teacher_init_prior_residual
   prior + residual gate，解释性更强，但 clean all-modal top1 和 no_prior 接近。

4. stage3 selective fine-tune
   解冻 GPS/mmWave 后 top1 有下降，暂不作为主模型。
```

新的目标不是继续调 scalar gate，而是实现一个更灵活的架构：

```text
MARF: Modality-Adaptive Routing Fusion
模态自适应路由融合
```

核心思想：

```text
不人工指定哪个模态是强模态。
模型根据当前样本、当前数据集、当前预测 horizon，动态决定：
1. 哪些模态作为 anchor 主导预测；
2. 哪些模态作为 residual 辅助补充；
3. 不同 horizon 可以依赖不同模态。
```

---

# 1. 新架构总览

新模型输入：

```text
image, lidar, radar, gps, mmwave
```

每个模态先通过单模态 teacher encoder 得到时序 token：

```text
z_m: [B, W, D]
```

其中：

```text
B = batch size
W = history length，例如 8
D = hidden dim，例如 256
K = 模态数量，例如 5
H = 预测 horizon，例如 3
C = beam 类别数，例如 64
```

整体结构：

```text
单模态 teacher encoders
        ↓
modality tokens z_m
        ↓
modality summaries u_m
        ↓
Dynamic Router
        ↓
anchor weights α_{m,h}
residual weights β_{m,h}
        ↓
Anchor Fusion
        ↓
h_anchor,h
        ↓
Residual Adapters
        ↓
Δh_{m,h}
        ↓
h_final,h = h_anchor,h + residual_scale * Σ β_{m,h} Δh_{m,h}
        ↓
beam classifier
        ↓
logits [B, H, C]
```

关键要求：

```text
1. 不允许写死 GPS/mmWave 是主干。
2. 不允许写死 Image/LiDAR/Radar 是残差。
3. 所有模态都可以成为 anchor。
4. 所有模态都可以成为 residual contributor。
5. prior 只作为初始化或弱偏置，不是固定规则。
6. router 必须是 sample-wise + horizon-wise。
```

z_m = projector_m(raw_feature_m)

# 5. 模块 2：ModalityRouter

新增文件：

```text
models/modality_router.py
```

## 5.1 目标

Router 为每个样本、每个 horizon、每个模态输出两个权重：

```text
anchor_weights α:   [B, H, K]
residual_weights β: [B, H, K]
```

含义：

```text
α_{b,h,m}: 第 b 个样本、第 h 个未来步，模态 m 作为主导 anchor 的权重。
β_{b,h,m}: 第 b 个样本、第 h 个未来步，模态 m 作为 residual 补充的权重。
```

## 5.2 输入

```python
modality_summary: Tensor[B, K, D]
confidence: Optional[Tensor[B, K, F_conf]]
modality_mask: Tensor[B, K]
modality_prior: Tensor[K]
```

`modality_summary` 由 token mean pooling 得到：

```python
u_m = mean_pool(z_m over W)
```

`confidence` 可选，当前先支持：

```text
1. 单模态 head confidence
2. entropy confidence
3. margin confidence
```

没有 confidence 时用零向量。

## 5.3 Router 结构

建议实现：

```python
class ModalityRouter(nn.Module):
    def __init__(
        self,
        num_modalities: int,
        d_model: int,
        horizon: int,
        hidden_dim: int = 256,
        conf_dim: int = 2,
        use_prior_bias: bool = True,
        use_modality_embedding: bool = True,
        router_temperature: float = 1.0,
    ):
        ...
```

每个模态输入特征：

```python
router_input_m = concat([
    modality_summary_m,       # [B, D]
    modality_embedding_m,     # [D]
    confidence_m,             # [F_conf]
    prior_m,                  # [1]
])
```

MLP 输出：

```python
router_out_m = MLP(router_input_m)  # [B, 2H]
```

拆成：

```python
anchor_residual = router_out_m.reshape(B, K, 2, H)

anchor_delta_logits:   [B, K, H]
residual_delta_logits: [B, K, H]
```

转置成：

```python
anchor_delta_logits:   [B, H, K]
residual_delta_logits: [B, H, K]
```

## 5.4 Prior bias

prior 不写死模态强弱，而是从 teacher registry 读取。
默认启用 prior bias：

```python
prior_logit = logit(clamp(prior, 1e-4, 1 - 1e-4))  # [K]
```

最终：

```python
anchor_logits = anchor_delta_logits + prior_anchor_scale * prior_logit[None, None, :]
residual_logits = residual_delta_logits + prior_residual_scale * prior_logit[None, None, :]
```

默认：

```yaml
prior_anchor_scale: 1.0
prior_residual_scale: 0.5
```

注意：

```text
prior 只是 bias，不是固定 gate。
不同数据集可以通过 teacher metric 自动生成 prior。
```

## 5.5 Mask 处理

不可用模态：

```python
anchor_logits = anchor_logits.masked_fill(~modality_mask[:, None, :], -1e9)
residual_logits = residual_logits.masked_fill(~modality_mask[:, None, :], -1e9)
```

Anchor 权重：

```python
anchor_weights = softmax(anchor_logits / temperature, dim=-1)
```

Residual 权重：

建议使用 sigmoid，但不可用模态置零：

```python
residual_weights = sigmoid(residual_logits)
residual_weights = residual_weights * modality_mask[:, None, :].float()
```

也可以加 residual sparsity：

```python
residual_weights = residual_weights * residual_mask
```

先不做 hard top-k。

# 6. 模块 3：AnchorFusion

新增文件：

```text
models/anchor_fusion.py
```

## 6.1 目标

根据 router 的 anchor 权重，对所有模态 token 做 horizon-wise anchor fusion。

输入：

```python
tokens: Tensor[B, K, W, D]
anchor_weights: Tensor[B, H, K]
token_padding_mask: Tensor[B, K, W]
```

输出：

```python
h_anchor: Tensor[B, H, D]
```

## 6.2 实现方式

每个 horizon 一个 learnable query：

```python
horizon_queries: nn.Parameter[H, D]
```

对第 h 个 horizon：

```python
weighted_tokens_h = tokens * anchor_weights[:, h, :, None, None]
```

flatten：

```python
memory_h = weighted_tokens_h.reshape(B, K * W, D)
mask_h = token_padding_mask.reshape(B, K * W)
```

cross attention：

```python
q_h = horizon_queries[h].expand(B, 1, D)

h_h, _ = cross_attn(
    query=q_h,
    key=memory_h,
    value=memory_h,
    key_padding_mask=mask_h,
)
```

最后拼接：

```python
h_anchor = concat over H  # [B, H, D]
```

类签名：

```python
class AnchorFusion(nn.Module):
    def __init__(
        self,
        d_model: int,
        horizon: int,
        num_heads: int = 4,
        dropout: float = 0.1,
    ):
        ...

    def forward(
        self,
        tokens: torch.Tensor,              # [B,K,W,D]
        anchor_weights: torch.Tensor,      # [B,H,K]
        token_padding_mask: torch.Tensor,  # [B,K,W]
    ) -> torch.Tensor:
        """
        return h_anchor: [B,H,D]
        """
```

# 7. 模块 4：ResidualAdapter

新增文件：

```text
models/residual_adapter.py
```

## 7.1 目标

每个模态都可以根据 anchor 表示提供 residual 补充：

```python
delta_m_h = Adapter_m(h_anchor_h, z_m)
```

输入：

```python
h_anchor: Tensor[B, H, D]
tokens: Tensor[B, K, W, D]
residual_weights: Tensor[B, H, K]
```

输出：

```python
residual_delta: Tensor[B, H, K, D]
residual_sum: Tensor[B, H, D]
```

## 7.2 适配器结构

建议先实现共享 adapter，而不是每个模态一个完全独立 adapter，提升泛化性。

类签名：

```python
class ResidualAdapter(nn.Module):
    def __init__(
        self,
        num_modalities: int,
        d_model: int,
        num_heads: int = 4,
        dropout: float = 0.1,
        residual_scale: float = 0.2,
        use_modality_embedding: bool = True,
    ):
        ...
```

对每个模态 m：

```python
query = h_anchor + modality_embedding_m
key = tokens[:, m, :, :]
value = tokens[:, m, :, :]

delta_m, _ = cross_attn(query, key, value)
```

得到：

```python
delta: [B, H, K, D]
```

加权：

```python
weighted_delta = residual_weights[:, :, :, None] * delta
residual_sum = weighted_delta.sum(dim=2)  # [B,H,D]
```

最后：

```python
h_final = LayerNorm(h_anchor + residual_scale * residual_sum)
```

默认：

```yaml
residual_scale: 0.2
```

不要一开始让 residual 影响太大。

新增文件：

```text
models/marf_model.py
```

## 8.1 类签名

```python
class MARFModel(nn.Module):
    def __init__(
        self,
        modalities: List[str],
        feature_dims: Dict[str, int],
        teacher_registry_path: str,
        d_model: int,
        history_len: int,
        horizon: int,
        num_classes: int,
        cfg,
    ):
        ...
```

## 8.2 forward

```python
def forward(
    self,
    features: Dict[str, torch.Tensor],
    modality_mask: torch.Tensor,
    force_modality_mask: Optional[torch.Tensor] = None,
    return_aux: bool = True,
):
    ...
```

有效 mask：

```python
effective_mask = modality_mask
if force_modality_mask is not None:
    effective_mask = modality_mask & force_modality_mask
```

流程：

```python
# 1. Encode each modality
tokens = []
for m in modalities:
    z_m = encoder_m(features[m])  # [B,W,D]
    z_m = z_m + time_embedding + modality_embedding
    tokens.append(z_m)

tokens = stack(tokens, dim=1)  # [B,K,W,D]

token_padding_mask = ~effective_mask[:, :, None].expand(B, K, W)

# 2. Summary
modality_summary = masked_mean(tokens, mask=token_padding_mask, dim=W)  # [B,K,D]

# 3. Confidence optional
confidence = compute_unimodal_confidence(...) or zeros

# 4. Router
router_out = router(
    modality_summary=modality_summary,
    confidence=confidence,
    modality_mask=effective_mask,
    modality_prior=prior_tensor,
)

anchor_weights = router_out["anchor_weights"]      # [B,H,K]
residual_weights = router_out["residual_weights"]  # [B,H,K]

# 5. Anchor fusion
h_anchor = anchor_fusion(tokens, anchor_weights, token_padding_mask)

# 6. Residual adapters
residual_out = residual_adapter(
    h_anchor=h_anchor,
    tokens=tokens,
    residual_weights=residual_weights,
    token_padding_mask=token_padding_mask,
)

h_final = residual_out["h_final"]

# 7. Classifier
logits = classifier(h_final)  # [B,H,C]
```

# 9. Loss 设计

## 9.1 主任务 loss

默认使用 CE + label smoothing，不使用 focal gamma=2。

```yaml
task_loss:
  type: "cross_entropy"
  label_smoothing: 0.03
```

原因：

```text
当前 ADBA 已经较高，Top-1 需要更关注精确分类。
focal gamma=2 可能过拟合 hard/noisy beam 边界样本。
```

## 9.2 Beam soft loss

保留，但权重较低：

```yaml
beam_soft_weight: 0.01
```

最多尝试：

```yaml
beam_soft_weight: 0.03
```

## 9.3 Residual norm loss

避免 residual 过大污染 anchor：

```python
loss_residual_norm = mean(||residual_weights * residual_delta||^2)
```

默认：

```yaml
residual_norm_weight: 0.001
```

## 9.4 Router entropy loss，可选

避免 anchor 权重过于平均：

```python
entropy = -sum(alpha * log(alpha))
loss_anchor_entropy = entropy.mean()
```

想让 router 更有选择性时启用：

```yaml
anchor_entropy_weight: 0.001
```

默认先设 0。

## 9.5 Prior regularization，可选

让 router 不要完全偏离 teacher metric prior：

```python
loss_prior = MSE(anchor_weights.mean(dim=(0,1)), prior)
```

默认较小：

```yaml
prior_reg_weight: 0.005
```

不要太大，否则模型会退化成固定 prior。

# 10. Subset-aware training

这是 MARF 的关键训练方式。新增文件：

```text
models/subset_sampler.py
losses/subset_losses.py
```

## 10.1 目标

让模型支持不同模态组合、不同数量、模态缺失。

每个 batch 同时训练：

```text
1. all modalities
2. top-prior subset
3. random subset
4. random subset with at least one high-prior modality
```

注意：

```text
不要写死 GPS/mmWave。
top-prior subset 根据 teacher_registry.json 中的 prior 自动决定。
```

## 10.2 Subset sampler

类签名：

```python
class ModalitySubsetSampler:
    def __init__(
        self,
        modalities: List[str],
        prior: Dict[str, float],
        min_keep: int = 1,
        max_keep: Optional[int] = None,
        top_prior_k: int = 2,
    ):
        ...

    def sample(
        self,
        modality_mask: torch.Tensor,  # [B,K]
        mode: str,
    ) -> torch.Tensor:
        """
        return force_modality_mask: [B,K]
        """
```

支持模式：

```text
all
top_prior
single_top_prior
random
random_with_top_prior
drop_one
```

### top_prior

选择 prior 最高的 top-k 模态。

例如 Scene32 上可能是：

```text
gps + mmwave
```

但其他数据集会自动变。

### random_with_top_prior

随机子集，但保证至少包含一个 top-prior 模态。

### drop_one

从所有可用模态中随机删除一个模态，用于 robustness。

---

## 10.3 Subset training forward

训练时：

```python
outputs_all = model(features, modality_mask, force_modality_mask=all_mask)
loss_all = task_loss(outputs_all["logits"], labels)
```

然后采样 N 个 subset：

```python
subset_masks = [
    top_prior_mask,
    random_with_top_prior_mask,
]
```

对每个 subset：

```python
outputs_subset = model(features, modality_mask, force_modality_mask=subset_mask)
loss_subset_ce += task_loss(outputs_subset["logits"], labels)
```

内部蒸馏：

```python
p_all = softmax(outputs_all["logits"].detach() / T)
log_p_subset = log_softmax(outputs_subset["logits"] / T)
loss_subset_kd = KL(log_p_subset, p_all) * T * T
```

总 loss：

```python
loss = (
    loss_all
    + subset_loss_weight * loss_subset_ce
    + subset_kd_weight * loss_subset_kd
    + beam_soft_weight * loss_beam
    + residual_norm_weight * loss_residual_norm
    + prior_reg_weight * loss_prior
)
```

推荐默认：

```yaml
subset_training:
  enabled: true
  num_subsets_per_batch: 2
  subset_loss_weight: 0.25
  subset_kd_weight: 0.10
  kd_temperature: 2.0
  modes:
    - "top_prior"
    - "random_with_top_prior"
```

# 12. 训练主循环修改

在 `train.py` 里新增 MARF 训练逻辑。

伪代码：

```python
for batch in train_loader:
    features = batch["features"]
    labels = batch["labels"]
    modality_mask = batch["modality_mask"]

    # all-modal forward
    outputs_all = model(
        features=features,
        modality_mask=modality_mask,
        force_modality_mask=modality_mask,
    )

    loss_all = task_loss(outputs_all["logits"], labels)

    loss_subset_ce = 0.0
    loss_subset_kd = 0.0

    if cfg.subset_training.enabled:
        subset_masks = []
        for mode in cfg.subset_training.modes:
            subset_mask = subset_sampler.sample(modality_mask, mode=mode)
            subset_masks.append(subset_mask)

        for subset_mask in subset_masks:
            outputs_subset = model(
                features=features,
                modality_mask=modality_mask,
                force_modality_mask=subset_mask,
            )

            loss_subset_ce += task_loss(outputs_subset["logits"], labels)

            with torch.no_grad():
                p_all = softmax(outputs_all["logits"] / T, dim=-1)

            log_p_subset = log_softmax(outputs_subset["logits"] / T, dim=-1)
            loss_subset_kd += kl_div(log_p_subset, p_all) * T * T

        loss_subset_ce /= len(subset_masks)
        loss_subset_kd /= len(subset_masks)

    loss_beam = beam_soft_loss(outputs_all["logits"], labels)
    loss_residual_norm = residual_norm_loss(outputs_all)
    loss_prior = prior_reg_loss(outputs_all["anchor_weights"], model.prior)

    loss = (
        loss_all
        + cfg.subset_training.subset_loss_weight * loss_subset_ce
        + cfg.subset_training.subset_kd_weight * loss_subset_kd
        + cfg.loss.beam_soft_weight * loss_beam
        + cfg.loss.residual_norm_weight * loss_residual_norm
        + cfg.loss.prior_reg_weight * loss_prior
    )

    loss.backward()
    optimizer.step()
```

# 22. 一句话目标

这次代码改进的核心目标是：

```text
从“teacher 初始化 + 普通多模态 Transformer”升级为
“teacher 初始化 + 动态模态路由 + horizon-wise anchor fusion + 条件 residual adapter + subset-aware training”。

模型不预设哪个模态强，而是根据数据集、样本和预测 horizon 自适应选择主导模态和辅助模态，从而提升 Top-1，并支持不同模态组合、模态缺失和模态失衡。
```
